# Алгоритмы
## Задачи при запуске run.bat
1. Обновление зависимостей
2. Получение чемпионов для текущей версии
3. Получение настроек и пресетов пользователя из бд
4. Инициализация бекенда
5. Запуск фронтенда
6. Запуск бекенда из фронтенда

## Действия при подключении к клиенту
1. Получаем мастерство чемпионов для каждой позиции
2. Получаем список очередей (режимов)


## ChampSelect фазы
1. Препик
2. Бан
3. Ожидание бана оставшихся игроков
4. Ождание показа банов врагов
5. Ождание пика других игроков
6. Пик
7. Ожидание пика оставшихся игроков
8. Финализация
