# Автоматическое принятие матчей в League of Legends

## Возможности
1. Автоматическое принятие матча в любом режиме
2. Бан чемпионов в ущелье призывателей
3. Пик чемпионов в ущелье призывателей
4. Просмотр riot id и рангов союзников во время поиска матча

## Quick Start
1. Скачайте архив с проектом ([Релизы](https://github.com/lavrocoder/accept_match_league_of_legend/releases))
2. Распакуйте в удобную для вас папку
3. Запустите `scripts/auto_match.bat` (Первый запуск установит всё необходимое и создаст нужные файлы)
4. Настройте пресеты героев 
5. Перезапустите `scripts/auto_match.bat`

## Настройка пресетов (пик и бан чемпионов)
1. Откройте файл `config/pick_and_ban_for_roles.txt` (он появится после первого запуска скрипта)
2. Введите имена чемпионов для пика и бана на каждую роль (каждого чемпиона с новой строки).
   - Для просмотра всех чемпионов можно запустить `scripts/champions_names.bat`
3. Бан чемпионов осуществляется только по этому пресету.
4. Пик чемпионов имеет следующие приоритеты:
   1. Чемпионы из пресета
   2. Чемпионы по максимальному мастерству (в соответствии с ролью)
5. Вы увидите таблицу героев когда запустите `scripts/auto_match.bat` (клиент должен быть открыт)

## Просмотр списка чемпионов League of Legends
1. Для просмотра списка всех чемпионов запустите `scripts/champions_names.bat`

## Обновление проекта
1. Запустите скрипт `scripts/update.bat`
2. Проект обновится, а все ваши настройки сохранятся
